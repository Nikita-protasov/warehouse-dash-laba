# Дашборд аналитики процесса управления складом

Интерактивное веб-приложение на базе **Python Dash** и **Plotly** для мониторинга финансовой эффективности и загруженности складских мощностей.

## Инструкция по запуску
1. Убедитесь, что активировано виртуальное окружение: `.\venv\Scripts\Activate.ps1`
2. Запустите приложение через терминал: `python app.py`
3. Откройте в браузере локальный адрес: `http://127.0.0`
4. Загрузите файл складских данных через веб-интерфейс (`warehouse_data.csv`).

## Структура визуальных элементов и аналитических панелей
* **Загрузчик файлов (Upload):** Инструмент динамического импорта складской отчетности. Расположен в самой верхней части страницы.
* **Выпадающий список (Dropdown):** Интерактивный фильтр по категориям грузов. Находится сразу под загрузчиком.
* **Индикаторы (KPI-карточки):** Три цветные панели, отображающие агрегированные суммы выручки (зеленая), расходов (красная) и чистой прибыли (синяя).
* **Линейный график:** Расположен слева в среднем блоке. Отображает динамику доходов и логистических расходов во времени.
* **Круговая диаграмма:** Расположена справа от линейного графика. Визуализирует долю затрат на обслуживание каждой категории товаров.
* **Гистограмма:** Находится в нижнем левом блоке. Анализирует частотное распределение маржинальности складских операций.
* **График рассеяния (Scatter plot):** Находится в нижнем правом блоке. Иллюстрирует зависимость между физическим объемом занимаемого груза (в кубических метрах) и полученной чистой прибылью.
* **Интерактивная таблица:** Детальный табличный массив в самом низу страницы с возможностью постраничного просмотра всех строк загруженного CSV-файла.
